# Claudia Zhang Portfolio Reference v1

这是根据参考图复刻的张晓彤 / Claudia Zhang AI 产品经理作品集第一版。

## Preview

本目录是静态网站，直接打开 `index.html` 即可预览。也可以在当前目录运行：

```bash
python3 -m http.server 4175
```

然后访问 `http://127.0.0.1:4175`。

## Structure

- `index.html` - 页面结构与个人信息
- `styles.css` - 色彩、布局、响应式样式
- `script.js` - 案例轮播、实验切换、导航、案例弹窗和邮箱复制
- `assets/` - 头像、插画、简历与作品集源文件

当前版本保留参考图的全屏章节、悬浮胶囊导航、圆角面板和作品切换语言，内容已经替换为简历中的 AI 产品经历与项目。
